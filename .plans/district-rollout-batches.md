# District rollout batches

The batch lists for `.plans/district-coverage-plan.md`. Each line is one rollout phase of up to 10 districts. Tick a box when the batch passes the checklist in the plan's §4.

**How the lists were made (Oct 27, 2026):**
- **Districts:** all 499 polygons in Harris County's `Permits/MUDandWaterDistricts_HCAD` layers (452 MUDs, 47 other water districts), minus MUD 489, which is already live.
- **Regions:** each district was placed in the school district that holds the center of its largest piece (Census TIGERweb unified school districts). A few near a school-district line may be in the wrong region. That only changes the order, not what gets built.
- **Order inside a region:** largest area first.
- **Format:** each district is listed as `HCAD code` + county-layer name. The code is **not** the MUD number: code `189` is MUD 489, and code `489` is MUD 189. Build IDs from the name, never the code.
- **Reshuffling:** after a region's site survey (plan §3), districts can move between that region's batches so sites built by the same vendor go together. Keep each batch at 10.
- **The X batches:** HCAD codes with no county boundary. Each one is reconciled before it's built (plan §5, X phases).
